## 📖 About The Project
This project is developed as part of the **CCS1303 - Object-Oriented Programming** module group project requirement at SLTC. The primary goal of this application is to solve a real-world problem using robust software engineering practices, emphasizing clean code, modular architecture, and the core pillars of Object-Oriented Programming.

---

## ✨ Key Features
- **User Authentication & Authorization:** Role-based access control for different users (e.g., Admin, Customer, Staff).
- **Core CRUD Operations:** Complete capability to Create, Read, Update, and Delete system records securely.
- **Data Persistence:** Persistent data storage handling using file handling / database integration.
- **Interactive Interface:** Clean and user-friendly interaction (Console / Graphical User Interface - GUI).
- **Error Handling:** Robust exception handling to prevent application crashes during invalid inputs or operations.

---

## 🧩 OOP Concepts Applied
The project heavily demonstrates industry-standard object-oriented design principles:
1. **Encapsulation:** Protecting data integrity by keeping fields private and providing controlled access via public getters and setters.
2. **Inheritance:** Creating a hierarchical class structure to promote code reusability (e.g., base user classes extended into specialized roles).
3. **Polymorphism:** Utilizing method overriding and interfaces to execute dynamic behavior at runtime.
4. **Abstraction:** Hiding complex implementation details and exposing only essential features using abstract classes and interfaces.

## ⚙️ Getting Started & Installation
To run this project locally on your machine, follow these steps:

### Prerequisites
- Java Development Kit (JDK) version 8 or higher (or your respective programming environment).
- An IDE such as IntelliJ IDEA, Eclipse, or VS Code.

### Steps to Setup:
1. Clone the repository:
   ```bash
   git clone https://github.com/MalithaDhananjaya/CCS1303-Object_Oriented_Programming-Group_project.git
   ```
2. Open the project in your preferred IDE.
3. Compile and Run the `Main` class to launch the application.
